（1）intval()使用不当导致安全漏洞的分析

intval函数有个特性:”直到遇上数字或正负符号才开始做转换，再遇到非数字或字符串结束时(\0)结束转换”,在某些应用程序里由于对intval函数这个特性认识不够,错误的使用导致绕过一些安全判断导致安全漏洞.此外有些题目还利用intval函数四舍五入的特性来绕过判断！

这里面有一句话写的特别好：当intval用在if等的判断里面,将会导致这个判断实去意义,从而导致安全漏洞。

PS：说明intval()转换的时候，会将从字符串的开始进行转换直到遇到一个非数字的字符。即使出现无法转换的字符串，intval()不会报错而是返回0

（7）借用反射来实现危险函数的调用

Reflection(反射)是Java程序开发语言的特征之一，它允许运行中的Java程序对自身进行检查，或者说“自审”，并能直接操作程序的内部属性。

概念

反射是指在PHP运行状态中，扩展分析PHP程序，导出或提出关于类、方法、属性、参数等的详细信息，包括注释。这种动态获取信息以及动态调用对象方法的功能称为反射API。

[23]数字的运算（intval($num) < 2020 && intval($num + 1) > 2021）

比如：[WUSTCTF2020]朴实无华 1

看起来几乎不可能，这个判定的条件是: 小于2020且+1大于2021
但是这个函数是：在输入是字符串的时候，intval会将传入的科学计数法取前面的整数，即2e4取2，即可绕过第一次的比较，在进行第二次的比较时进行了运算，重新转换为了科学计数法
但是这个版本比较低，举个例子：

PHP 4.x、PHP 5.0–5.2
intval(“2e4”) 结果 为 2
PHP 5.3+、PHP 7.x、PHP 8.x
intval(“2e4”) 结果 为 20000
因为从 PHP 5.3 起，intval() 会尝试先将字符串转成 float（如果可以），然后再转成 int
